# E-CFunds

Fund monitoring app for OMSC Office of Student Affairs clubs and organizations: dues collection, remittances, fund releases, expenses and transparent financial reports.

**Status:** planning complete, build starting. See [`docs/plan.md`](docs/plan.md).

## Stack
React + TypeScript + Vite + Tailwind · Supabase · Vercel · PWA + Capacitor (Android)

## Roles
- **SAS Admin**: oversees all orgs and clubs, approves remittances, releases funds
- **Treasurer**: manages their org's students, dues, remittances and expenses
- **Student**: views school-wide and per-org financial reports and their own dues
